# rico-slides — Gemini Notebook で「見た目の整った日本語スライド」を作るスキル

Gemini Notebook に持ち込んで使う、**日本語のビジネススライド専用**のエージェントスキルです。
研修資料・報告・説明会・提案の資料を、**編集できる PowerPoint（16:9）** として作ります。

Python と python-pptx だけで動くので、手元のパソコンや他の AI ツールでも使えます。
ただし**動作を確認しているのは Gemini Notebook と手元のパソコン**です。

作者: リコのAIラボ（RICO's AI Lab） / ライセンス: MIT

---

## 何が変わるか

ふつうに「スライドを作って」と頼むと、文字が小さかったり、どのページも同じ配置だったり、
色がちぐはぐだったりします。このスキルを持ち込むと、AI が次の作法で作ります。

- **描き始める前に設計表を書く**（何枚目にどの構図を使い、どの語を強調するか）
- **全ページを違う組み立てにする**（表紙・目次・章扉・チェックリスト・大きな数字・タイムラインなど13種類）
- **配色は10種類から選ぶ**（迷ったら聞いてくれます。会社の色を指定することもできます）
- **描き終えたら自分で検品する**（文字の大きさ・枠からのはみ出し・文字の重なり・見出しの長さ）
- **各ページに発表原稿を入れる**（そのまま読み上げられます）

## Gemini Notebook での使い方

### 1. このスキルを取り込む

変換ツールに、このページのアドレスを貼ります。

```
https://github.com/ricoaiproject-cmd/rico-slides-for-gemini-notebook/tree/main/rico-slides
```

変換ツールは動画の概要欄で配布しています。フォルダをまとめて、
Gemini Notebook が受け取れる形（文字だけのファイル）に変えてくれます。

手元にダウンロードしてから、同じツールの「手元のファイルを変換する」に入れても構いません。

### 2. できたファイルを Gemini Notebook のソースに入れる

「ソースを追加」から、変換されたファイルをアップロードします。

### 3. 設定に1回だけ貼る

Gemini Notebook の **設定 ＞ チャットを設定 ＞ カスタム** に、次を貼ります。
ファイル名は、実際にアップロードしたものに合わせてください。

```
作業を頼まれたら、まず /workspace/knowledge/ の （ファイル名） を base64 デコードして
zip として /workspace/scratch/ に展開し、rico-slides/SKILL.md に従って作業すること。
展開は毎回やり直すこと。
```

貼るのはこの1回だけです。

### 4. あとは普通に頼む

```
情報セキュリティ規程の研修資料を PowerPoint で5枚作って
```

配色を指定しなければ、10種類の一覧を出して選ばせてくれます。
イラストを入れるかも同時に聞いてきます。

**「スライドを作って」ではなく「PowerPoint で作って」と言ってください。**
「スライド」と言うと、Gemini Notebook が自分の持っているスライド作成機能のほうを使ってしまい、
このスキルが使われません。

## 手元のパソコンで使う

```bash
pip install python-pptx pillow
```

```python
import sys; sys.path.insert(0, "rico-slides/scripts")
from slide_helpers import Deck

d = Deck(palette="ink-coral")
d.cover("情報セキュリティ\n基本の4か条", "新入社員研修", eyebrow="総務部",
        accent_word="4か条", notes="発表原稿をここに")
s = d.slide("情報は4つに分類して扱う", accent="4つ", eyebrow="第3条",
            notes="発表原稿", depth="numeral:4")
d.checklist(s, ["極秘|経営判断に直結する情報", "秘|人事・契約・顧客の情報",
                "社外秘|社内限定の資料", "公開|誰が見てもよい情報"])
d.takeaway(s, "自分が扱う情報が、どの区分かを先に確かめる")
d.save("deck.pptx")   # 保存と同時に検品が走ります
```

## 中身

```
rico-slides/
├ SKILL.md              手順書（AI はこれを読んで動きます）
├ references/
│  ├ 01_layout.md       余白・文字の大きさ・1枚の情報量
│  ├ 02_color.md        配色10種と、会社の色を使うときの組み立て方
│  ├ 03_compositions.md 構図13種（表紙・目次・章扉・チェックリスト・大きな数字ほか）
│  └ 04_checklist.md    納品前の確認事項
├ scripts/
│  ├ slide_helpers.py   スライドを描く部品
│  ├ pptx_slide_gate.py 検品プログラム
│  └ make_backgrounds.py 背景画像を作り直すとき用
├ assets/               文字なしの背景画像3枚
├ LICENSE               MIT
└ FORK_NOTES.md         このスキルの出自
```

## 配色

| 名前 | 主な色 | 向いている場面 |
|---|---|---|
| ink-coral | インクネイビー × コーラル | 既定。社内資料・報告 |
| navy-brass | ダークネイビー × 真鍮 | 金融・士業・伝統企業 |
| graphite-blue | グラファイト × ブルー | テック・スタートアップ |
| charcoal-mint | チャコール × ミント | 建築・デザイン・不動産 |
| mono-lime | モノクロ × ライム | 動画映え・若い会社 |
| moss-clay | モスグリーン × テラコッタ | 食・農・地域・環境 |
| cocoa-gold | ココアブラウン × ゴールド | 高級・式典・ホテル |
| plum-ash | プラム × アッシュ | 和・文化・自治体 |
| ocean-sky | オーシャンブルー × スカイブルー | 医療・ヘルスケア |
| sand-terra | サンドベージュ × テラコッタ | カフェ・雑貨・採用 |

一覧にない色（会社のコーポレートカラーなど）も指定できます。
色の明るさを見て主役に使えるか判断し、相性の悪い差し色は自動で選び直します。

## 注意

- Gemini Notebook の裏側は**インターネットにつながっていません**。このスキルは資料もプログラムも
  すべてフォルダの中にあるので、そのまま動きます。
- 日本語フォントは **Meiryo** を指定しています。環境に無い場合は別のフォントに置き換わります。
- Gemini Notebook で画像を生成すると隅に印が入りますが、下端を自動で切り落とすので写り込みません。
