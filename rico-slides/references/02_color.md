# 配色（スライド専用）

## 配色比率 70 : 25 : 5
- **ベース（70%）**: 背景・カード面。主張しない色。
- **メイン（25%）**: 見出し帯・キー図形・主要数値。ブランド色。
- **アクセント（5%）**: 1枚につき1か所だけ（強調する数値1つ、またはキーワード1語）。
- 使う色は **6色＋派生2色に固定**: Key / Accent / Surface / Body / Muted / White と、Key から機械的に作る **Tint**（Key を白に 92% 寄せた薄い色。奥行き用の大きな図形・巨大な薄い数字）・**Shade**（Key を黒に 10% 寄せた暗い色。表紙の縦帯）。派生2色は `slide_helpers.tint()` が計算するので、自分で色コードを書かない。この8色以外を使わない。
- 純色・#000000・#FFFFFF を生で使わず一段外す（例: #1A1A1A、#FAFAF7）。ただし White は #FFFFFF でよい。

## コントラスト
- 本文級の文字は背景と **4.5:1 以上**、大きな文字（24pt 以上）は **3:1 以上**。
- 濃い帯の上の文字は White。薄い面の上の文字は Body。Key の上に Accent を置かない。

## CUD（色覚多様性）
- 色の違いだけに情報を担わせない（ラベルを直書き、形や位置でも区別）。
- 赤×緑、橙×黄緑、紫×青を隣接させない。

## 一覧に無い色を指定されたとき（会社の色・好きな色）

**色を自分で発明しない。**10 種のどれかを土台にして、**Key だけ差し替える**。Accent・Surface・Body・Muted は
実績のある組み合わせをそのまま借りる。これで破綻を防ぐ。

手順は4つ。

1. **指定色を受け取る。**色コード（#1B3557）でも、色名（紺、えんじ）でも、「うちのコーポレートカラー」でもよい。
   色名しか分からないときは代表的な色コードに直す（紺なら #1F3864 など）。
2. **明るさを見て、Key に使えるか判断する。**
   明度（0〜255 に直したときの明るさ）が **110 より明るい色は Key に使えない**。白い文字が乗らず読めなくなる。
   その場合は次のどちらかにする。**どちらにしたかを一言伝える。**
   - その色を **Accent（1点強調）にまわし**、Key は色相の近い 10 種の Key を使う
   - その色を **暗くして Key にする**（`tint()` の逆で黒に寄せる。目安は明度 70〜100 に収める）
3. **色相がいちばん近いパレットを 10 種から選ぶ。**赤系なら ink-coral、青系なら navy-brass か graphite-blue、
   緑系なら charcoal-mint か moss-clay、茶・金系なら cocoa-gold か sand-terra、紫系なら plum-ash、
   水色系なら ocean-sky。迷ったら ink-coral。
4. **そのパレットを丸ごとコピーして、Key だけ指定色に置き換える。**Surface は指定色から
   `tint(指定色, 0.94)` で作り直す（元の Surface のままだと色がちぐはぐになる）。Body・Muted は触らない。
5. **Accent（差し色）は、Key と色相が近すぎないか確かめる。**
   色相環の角度で **30 度以内なら近すぎる**。赤い Key に赤い Accent を重ねると、強調が効かず全体が濁る
   （実測: 金赤 #E60033 を Key にしたとき、土台 ink-coral の Accent #E2553F をそのまま使って
   赤に赤を重ねる失敗が出た）。近すぎたら、**土台から借りずに次の対応表から選び直す**。

   | Key の系統 | 使う Accent | 色コード |
   |---|---|---|
   | 赤・朱・金赤 | 濃い紺 | 1B3557 |
   | 橙・茶・金 | 深い青緑 | 156B6B |
   | 黄・黄緑 | 濃い紫 | 5A3E7A |
   | 緑・青緑 | 赤茶（テラコッタ） | C2452F |
   | 青・紺・水 | 真鍮（くすんだ金） | C9992F |
   | 紫・赤紫 | 深い黄土 | B08234 |

   選び直したときは「差し色は◯◯にしました」と**一言伝える**。
   なお Accent は**面積の 5% だけ**に使う色なので、Key より目立つ必要はない。落ち着いた色でよい。

```python
from slide_helpers import PALETTES, tint, Deck
c = dict(PALETTES["navy-brass"])      # 色相が近い土台
c["key"] = "1F3864"                    # 指定された色
c["surface"] = tint(c["key"], 0.94)    # 面の色だけ作り直す
d = Deck(custom=c)                     # Tint / Shade / accent_text は自動で作られる
```

**検品ゲートに渡す色も差し替える。**`palette_arg(d.c)` の戻り値をそのまま `--palette` に渡せば、
指定外の色として弾かれることはない。

**2色以上を指定されたとき**は、**濃いほうを Key、鮮やかなほうを Accent** にする。3色以上は受け取らない
（「主役の色と、差し色を1つだけ教えてください」と聞き返す）。色が増えるほど資料は散らかる。

## 鮮やかすぎる Key は、面積を絞る（実測で判明・令和8年9月19日）

10 種の Key はどれも彩度が低い（くすんだ濃色）。**ここに彩度の高い色を持ち込むと、同じ設計でも刺さって見える。**

判定は **彩度（0〜100）が 70 以上**かどうか。該当したら次の2つを守る。

- **表紙を主役色で全面塗りにしない。**地は Surface（淡い面）にして、主役色は**左の縦帯と見出しの下線だけ**に使う。
  主役色の面積は画面の **3割以内**に収める。
- **主役色の上に差し色を置かない。**見出しの強調語は、主役色の地の上なら **White**、淡い地の上なら差し色を使う。
  （実測の失敗: 金赤 #E60033 の地に濃紺の強調語を置き、読みづらくなった）

彩度が 70 未満（10 種と同じくらい落ち着いた色）なら、これまでどおり表紙は主役色の全面塗りでよい。

```python
import colorsys
r, g, b = [int(key[i:i+2], 16)/255 for i in (0, 2, 4)]
sat = colorsys.rgb_to_hsv(r, g, b)[1] * 100      # 彩度
vivid = sat >= 70                                 # True なら面積を絞る
```

## パレット 10 種（そのまま使う。題材に合わせて1つ選ぶ。依頼に色の指定があればそれを優先）
組み方はどれも同じ: **濃い Key（地）＋淡い Surface（面）＋強い Accent（1点）** の3役で、彩度をそろえる。色を足さない。

|---|---|---|---|---|---|---|
| ink-coral | #27384A | #E2553F | #EEF1F4 | #262E36 | #76808A | 既定。社内資料・IT・報告 |
| navy-brass | #1B3557 | #C9992F | #F5F8FB | #1E2833 | #6C7885 | 金融・士業・伝統企業 |
| graphite-blue | #303B4C | #2F7FD1 | #E6EBF1 | #222A34 | #737E8C | テック・スタートアップ |
| charcoal-mint | #1D2430 | #3BA776 | #F4F7F9 | #1D2430 | #6B7480 | 建築・デザイン・不動産 |
| mono-lime | #18181B | #93C830 | #F1F1F1 | #1A1A1A | #6E6E6E | 白黒＋ライム。動画映え・若い会社 |
| moss-clay | #2E6B4F | #C2452F | #F6F2E8 | #24352C | #6E7A72 | 食・農・地域・環境 |
| cocoa-gold | #3A2E2C | #B9924A | #EDE2D2 | #2C2523 | #7B706C | 高級・式典・ホテル |
| plum-ash | #5A4A57 | #D9553D | #E3DCCB | #2E282C | #7D7078 | 和・文化・自治体 |

- White は全パレット共通で #FFFFFF。Tint・Shade・AccentText はパレットごとに `Deck` が自動生成する（`palette_arg(d.c)` で9色をまとめて取り出し、検品ゲートの `--palette` に渡す）。
- **AccentText**: 白地に置く強調語の色。Accent が明るくて白と 3:1 に届かないとき（mono-lime のライムなど）だけ、同じ色相のまま暗くした色になる。帯の点や図形には Accent、白地の文字には AccentText。ヘルパーが使い分けるので自分で選ばない。
- 会社指定色があるときは、Key をその色に置き換え、Accent は Key の補色寄りで彩度を1段落とした色にする。

## 色の役割（固定）
- 見出し帯: Key 塗り + White 文字。
- カード: Surface 塗り、枠線なし（または Muted 0.75pt）。
- 主要数値: Key。強調する1点だけ Accent。
- 罫線・矢印・タイムラインの線: Key（細線 1.5pt）。点: Accent は1つだけ、他は Key。
- 注記・出典・ページ番号: Muted。
- 奥行き（1枚に1手まで）: Tint の大きな円・帯、または Tint の巨大な数字。文字と重ねない。
- 持ち帰り帯: Key 塗り + White 文字、左端に Accent の小さな点。
